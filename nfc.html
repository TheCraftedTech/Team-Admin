NFC-TEST

Prüft, ob dieses Handy NFC-Tags im Browser lesen kann. Zum Lesen auf „Tag lesen starten“ tippen und dann das Handy an den Tag halten.

Systemcheck

1) Tag lesen (Web NFC)

Noch nicht gestartet.

2) Tag beschreiben (zum Vorbereiten, nur Android/Chrome)

Nach dem Tippen das Handy an einen leeren oder überschreibbaren Tag halten.

3) Tag öffnet einen Link (geht auch auf dem iPhone)

Wird ein Tag mit einem Link beschrieben, öffnet das Handy diesen Link, sobald man es an den Tag hält – ohne dass die Seite etwas lesen muss. Das klappt auch auf dem iPhone (XS und neuer, Display an: es erscheint eine Meldung, die man antippt).

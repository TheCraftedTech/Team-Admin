# DER HAUSER-BRUNNEN

Ihr habt den **Hauser-Brunnen** erreicht. Das Signal ist jetzt so stark, dass es die Funkgeräte der Aliens zum Leuchten bringt.

Sie sind sehr still geworden. Irgendetwas an diesem Ort ist für sie wichtig – aber was, das müsst ihr herausfinden.

Nehmt euch einen Moment Zeit und schaut euch den Brunnen genau an.
